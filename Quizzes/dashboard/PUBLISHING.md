# Publishing The Quiz Dashboard

## Recommended Phone Setup

1. Publish this repository with GitHub Pages.
2. Open the published dashboard URL on your phone:
   `https://qianshanhe.github.io/DS_Academy/Quizzes/dashboard/`
3. On iPhone, open the URL in Safari, tap Share, then choose Add to Home Screen.
4. Create an iPhone Reminder or Calendar event with the dashboard URL for reliable push notifications.
5. After the URL is live, update the Codex daily reminder to point to the published URL instead of the local file path.

## GitHub Pages Settings

For a repository named `DS_Academy`, the default GitHub Pages project URL is:

`https://qianshanhe.github.io/DS_Academy/`

The dashboard should then be available at:

`https://qianshanhe.github.io/DS_Academy/Quizzes/dashboard/`

If the repository is private, GitHub Pages availability depends on the GitHub plan and repository settings.
