# DS Academy Quiz Dashboard

Open `index.html` in a browser to take daily and weekly DS Academy quizzes.

The dashboard includes:

- Multiple-choice and free-response questions.
- Immediate feedback after submission.
- Attempt history saved in browser storage.
- Weak-area tracking based on missed questions.
- JSON export for attempts.
- Home Screen install support after the dashboard is hosted over HTTPS.

This version is static and does not need a build step. Browser storage is local to the browser and device where you take the quiz.

For phone use, publish this folder through HTTPS, such as GitHub Pages, then open the published URL on the phone and add it to the Home Screen.

Expected GitHub Pages URL if this workspace is published as `qianshanhe/DS_Academy`:
